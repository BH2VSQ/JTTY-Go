# JTTY-Go Alpha v5.15

## UI
- Reworked the main operating controls to match the supplied WSJT-X reference layout.
- Moved the RF frequency display into the operating area.
- Added a full-width band shortcut row and compact action toolbar.
- Grouped RX/TX offsets, tolerance, DX Call/Grid, UTC clock, serial number, message entry, macros and TX queue into one scroll-free operating region.
- Removed the former standalone rig bar from the main window.
- Kept audio device selection exclusively in Configuration -> Audio.
