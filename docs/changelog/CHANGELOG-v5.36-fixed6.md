# JTTY-Go v5.36-fixed6

## 修复

### 1. 解码窗口按 UTC 时间正序显示

- 左侧“所有解码”改为严格按照 `signalUtc` 从旧到新排序。
- 最旧消息显示在顶部，最新消息显示在底部。
- 解码线程完成顺序与信号实际时间顺序不一致时，后到的旧消息会插入到正确的时间位置，不再造成显示顺序倒置。
- 多帧 JTTY 消息的更新仍然保持同一条记录，但更新后会重新放回其正确的时间位置。

### 2. 防止同一消息 ID 覆盖历史解码

- JTTY 消息 ID 改为进程级原子递增分配。
- 监听停止后重新启动、重新建立接收流时，不再从 1 重新分配消息 ID。
- 避免新一轮监听产生的消息因为 ID 重用而把旧解码记录错误覆盖。

### 3. 启动时自动刷新快捷消息名称

- 增加 `settings:get` 启动同步事件。
- 前端完成 Wails 事件监听后主动请求一次当前设置，确保启动时直接读取本地配置文件。
- `settings:state` 收到后立即重绘主界面快捷消息按钮，因此无需再进入“设置 → 快捷消息”后保存才能显示自定义名称。

### 4. 前端配置类型补全

- 补充 `readPowerSWR` 与 `haltOnSWR` 前端设置类型及默认值，避免 TypeScript 类型检查报错。
