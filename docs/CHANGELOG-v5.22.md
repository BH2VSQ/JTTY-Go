# JTTY-Go v5.22

本版继续遵循“**不修改现有设计结构，只填充功能对接**”。界面层级、设置页组织、主操作区布局保持不变。

## 功能对接

- RX 音频电平：从实际 PCM 接收帧计算 dBFS，并以事件方式更新现有横向电平表。
- 电台表：通过 Hamlib `get_level` 能力发现并轮询 `STRENGTH`、`ALC`、`RFPOWER_METER`、`RFPOWER_METER_WATTS`、`SWR`。
- 多信号接收：检测器输出的稳定频率候选直接作为 JTTY 解码搜索提示，减少解码器在固定中心频率上盲搜。
- 手动解码：立即解码使用当前缓冲区中最近的完整 JTTY 帧。
- JTTY 解码器的最小 SNR 已提供运行时接口，为后续解码菜单扩展保留对接点。
- 发射开始/结束立即同步电台表的 TX 状态，避免等待下一次轮询。
- 电台断开时主动清空电平数据与能力状态。
- 电台频率设置仅在 CAT 成功后更新本地已确认频率。
- RX/TX 音频频率输入范围与当前界面统一为 200–5000 Hz。

## 参考原则

功能边界参照 WSJT-X 的 Audio、Detector、Decoder、Modulator、Transceiver 和 logbook 等职责划分；本项目继续使用 Go 内部模块 + Wails 事件桥接，而不重构既有前端布局。
