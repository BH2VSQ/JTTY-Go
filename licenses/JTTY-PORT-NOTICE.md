# JTTY implementation notice

JTTY-Go contains a Go reimplementation of the JTTY algorithms based on study
of the user-provided WSJT-X 3.2.0-rc1 source archive. The selected upstream
JTTY reference sources are preserved under `reference/wsjtx-jtty/` together
with the upstream `COPYING` file.

The reference implementation is a component of WSJT-X and is subject to its
license and source notices. JTTY-Go should retain the corresponding notices
when distributing code derived from the reference implementation.

This notice is not a substitute for legal review of the final distribution
model. Before distributing binaries, verify the complete license obligations
for every included or derived component.
